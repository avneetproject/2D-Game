# SpaceJam - Raylib C Game

SpaceJam is a 2D arcade-style space shooter built using **raylib** in **C**.

You control a spaceship in open space while meteors continuously fly toward you from different directions. Your objective is simple: survive as long as possible by shooting incoming meteors before they hit you.

The game progressively increases in difficulty, creating a fast-paced survival experience.

---

## Gameplay Overview

- Move your spaceship using **W, A, S, D**
- Shoot using **Left Mouse Button (LMB)**
- Destroy incoming meteors before they collide with you
- Collect power-up to gain abilities
- Survive as difficulty increases over time

---

## Core Mechanics

### Meteor System
- Meteors spawn from multiple directions
- They move toward the player
- Spawn rate increases over time
- Meteor speed gradually increases
- Multiple meteors can be active simultaneously

### Shooting System
- Mouse-based shooting
- Projectiles travel toward cursor direction
- Collision detection between bullets and meteors

### Power-Up System
- Special power-ups appear during gameplay
- Triple-shot ability allows firing three projectiles at once
- Encourages aggressive and strategic play

### Progressive Difficulty
- Increasing meteor speed
- Increasing spawn frequency
- Higher pressure as time passes
